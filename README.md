# du3-photo-app

The static front page of the DU3 Photo App, served by GitHub Pages at https://photo.sst.works .

DU3 Tooling. Code only (DU3 Records Rules B12, D8): no records, data, PINs, keys or personal details live here. The page talks to the DU3 Photo App server (an Apps Script web app) as a JSON API; PINs, uploads, the photo register, unit cards and work orders stay server-side.

Clone-ready (prime directive 2): the server address and any project-specific settings sit in one config block at the top of index.html, so a cloned project repoints them in one place.
